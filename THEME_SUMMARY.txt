┌─ KEY FEATURES ───────────────────────────────────────────────────────────┐
│                                                                           │
│  🎨 TWO BEAUTIFUL THEMES:                                               │
│     • Light Mode: Clean, professional appearance                        │
│     • Dark Mode: Easy on the eyes, modern look                          │
│                                                                           │
│  🔄 SMART DETECTION:                                                    │
│     • Auto-detects OS theme preference on first visit                   │
│     • Remembers user's choice in localStorage                           │
│     • Respects system theme changes (unless user overrides)             │
│                                                                           │
│  🎯 EASY TO USE:                                                        │
│     • Toggle button in top-right corner                                 │
│     • Sun icon in light mode / Moon icon in dark mode                   │
│     • One-click switching with smooth animation                         │
│                                                                           │
│  ⚡ HIGH PERFORMANCE:                                                    │
│     • No JavaScript framework required                                  │
│     • CSS variables for instant color switching                         │
│     • No flickering on page load                                        │
│     • Minimal file size impact                                          │
│                                                                           │
│  ♿ ACCESSIBLE:                                                          │

┌─ HOW IT WORKS ───────────────────────────────────────────────────────────┐
│                                                                           │
│  FOR USERS:                          FOR DEVELOPERS:                    │
│  1. Visit website                    1. Colors use CSS variables       │
│  2. See OS theme automatically      2. Easy to customize              │
│  3. Click toggle button              3. Just wrap pages in BaseLayout  │
│  4. Theme switches instantly         4. No dependencies needed         │
│  5. Preference is saved              5. Production ready              │
│  6. Next visit: theme persists       6. Works in all browsers          │
│                                                                           │

┌─ QUICK START ─────────────────────────────────────────────────────────────┐
│                                                                           │
│  1. DEVELOPMENT:                                                        │
│     $ npm run dev                                                       │
│     • Visit http://localhost:3000                                       │
│     • Look for toggle button (top-right corner)                         │
│     • Click to switch themes                                            │
│                                                                           │
│  2. CUSTOMIZATION:                                                      │
│     • Edit CSS variables in: src/layouts/BaseLayout.astro              │
│     • Change light mode colors in :root selector                        │
│     • Change dark mode colors in [data-theme='dark'] selector           │
│                                                                           │
│  3. ADD TO NEW PAGES:                                                   │
│     ---                                                                 │
│     import BaseLayout from '../layouts/BaseLayout.astro';              │
│     ---                                                                 │
│     <BaseLayout title="My Page">                                        │
│       Your content here                                                 │
│     </BaseLayout>                                                       │
│                                                                           │
│  4. DEPLOY:                                                             │
│     $ npm run build                                                     │
│     • Deploy dist/ folder as usual                                      │
│     • Theme system works everywhere!                                    │
│                                                                           │
